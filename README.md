## 🌟 Overview

This repository contains the complete, production-ready website for **VAINAN 3D CARE PVT LTD**, a leading digital dentistry and additive manufacturing center. The platform is engineered with an industrial B2B aesthetic, modern mobile responsiveness, and high-performance vanilla architecture.

### Key Capabilities & Specialized Divisions
1. **Pillar A — Core Dental Manufacturing:** Industrial Laser Powder Bed Fusion (TRUMPF TruePrint 1000 DMLS), 5-axis precision milling (Versamill), custom titanium bases, and full-mouth rehabilitations.
2. **Pillar B — Vainan 3D Aligners:** Direct 3D-printed shape-memory aligners and automated multi-stage thermoforming lines with high-end clinical packaging suites.
3. **Pillar C — Education & Hands-on Workshops:** Certified surgical guide planning, dual-screen Exocad workstations, and hands-on digital implantology training.

## 🛠️ Technology Stack

- **Markup:** Semantic HTML5 with SEO meta tags, OpenGraph attributes, and accessible ARIA attributes.
- **Styling:** Custom Vanilla CSS3 Master Design System (`css/style.css`) with CSS custom properties (tokens), responsive typography (`clamp()`), and industrial teal (`#1FA88C`) accents.
- **Interactivity:** Vanilla JavaScript (`js/main.js`) powering:
  - Mobile slide-out navigation drawer with backdrop blur and touch gestures
  - Sticky mobile floating bottom action bar (Call, WhatsApp, Order Rx, Rate List)
  - Horizontal swipe hint and sticky-first-column table navigation on mobile
  - Horizontally scrollable category filter tabs carousel
  - Interactive inquiry form simulation & Back-to-Top button
- **Zero Heavy Frameworks:** Ultra-fast load times, 100% static hosting compatibility.

## 🌐 Hosting & Deployment Guide

This project is 100% static and can be deployed with zero configuration on any modern hosting provider:

### Option 1: Vercel (Recommended)
1. Import this GitHub repository into [Vercel](https://vercel.com).
2. Framework Preset: **Other** / None.
3. Root Directory: `./`
4. Click **Deploy**.

### Option 2: Cloudflare Pages
1. Go to **Cloudflare Dashboard > Pages**.
2. Connect to this GitHub repository.
3. Build command: None (leave blank).
4. Output directory: None / Root (`/`).
5. Click **Deploy**.

### Option 3: GitHub Pages
1. Go to **Settings > Pages** in this repository.
2. Under **Branch**, select `main` and `/ (root)`.
3. Click **Save**.

### Option 4: Netlify
1. Connect repository in [Netlify](https://www.netlify.com).
2. Publish directory: `.`
3. Click **Deploy Site**.
